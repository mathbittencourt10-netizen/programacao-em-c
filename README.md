# 💻 Programação em C

Coleção de exemplos e projetos em C organizados por categoria,  
cobrindo desde os fundamentos da linguagem até projetos interativos.

---

## 📁 Estrutura do repositório

```
programacao-em-c/
├── fundamentos/
│   ├── 01_basico.c            # Tipos de dados, variáveis, operadores, I/O
│   └── 02_controle.c          # if/else, switch, for, while, do-while
├── funcoes/
│   └── 03_funcoes.c           # Funções, recursão (fatorial, Fibonacci), primos
├── estruturas/
│   ├── 04_arrays_strings.c    # Vetores, matrizes, bubble sort, strings
│   └── 05_ponteiros.c         # Ponteiros, passagem por referência, alocação dinâmica
└── projetos/
    ├── calculadora.c           # Calculadora interativa via terminal
    └── jogo_forca.c            # Jogo da forca com palavras da área de TI
```

---

## 🚀 Projetos em destaque

### 🧮 Calculadora Interativa
Calculadora via terminal com suporte a `+`, `-`, `*` e `/`.  
Trata divisão por zero e entradas inválidas.

### 🪢 Jogo da Forca
Jogo da forca com palavras do vocabulário de programação.  
Inclui display visual da forca, controle de tentativas e opção de repetir.

---

## 🛠️ Como compilar e executar

### Linux / macOS
```bash
gcc fundamentos/01_basico.c -o 01_basico
./01_basico
```

### Windows (com MinGW/GCC instalado)
```bash
gcc fundamentos\01_basico.c -o 01_basico.exe
01_basico.exe
```

> **Dica:** compile qualquer `.c` com `gcc nome_do_arquivo.c -o saida`

## 📚 Conteúdo por arquivo

| Arquivo | Conceitos abordados |
|---|---|
| `01_basico.c` | Tipos primitivos, scanf/printf, operadores aritméticos e lógicos |
| `02_controle.c` | if/else, switch/case, for, while, do-while, tabuada |
| `03_funcoes.c` | Funções, protótipos, recursão, fatorial, Fibonacci, primos |
| `04_arrays_strings.c` | Vetores, matrizes, bubble sort, busca linear, strlen, strcat |
| `05_ponteiros.c` | Ponteiros, passagem por referência, aritmética de ponteiros, malloc/free |
| `calculadora.c` | Estruturas de controle, switch, loop infinito, leitura de operador |
| `jogo_forca.c` | Strings, arrays, funções, rand/srand, lógica de jogo |
